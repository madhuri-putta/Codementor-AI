# 🚀 CodeMentor AI

CodeMentor AI is an AI-powered coding assistant that provides real-time debugging and context-aware programming support.  
It leverages Large Language Models (LLMs) and prompt engineering techniques to generate accurate, optimized solutions for developers.

---

## ✨ Features

- 🧠 AI-powered real-time debugging
- 💡 Context-aware code suggestions
- ⚡ Optimized and accurate solution generation
- 🔍 Intelligent error detection and explanation
- 🌐 Scalable backend using FastAPI
- 🎨 Interactive frontend built with React

---

## 🛠️ Tech Stack

### Backend
- Python
- FastAPI
- LLM APIs (OpenAI )
- Prompt Engineering

### Frontend
- React.js
- Axios (API integration)
- HTML, CSS, JavaScript

### Other Tools
- Git & GitHub
- REST APIs
- Virtual Environment (venv)
